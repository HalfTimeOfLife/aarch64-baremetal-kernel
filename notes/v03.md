# v0.3 - ARM Timer

---

## Step 0: The ARM Generic Timer

For this version, I used the official [Learn the architecture - Generic Timer](https://developer.arm.com/-/media/Arm%20Developer%20Community/PDF/Learn%20the%20Architecture/Generic%20Timer.pdf) documentation of AArch64.


Each AArch64 core has a built-in generic timer, exposed through system registers (like UART or GIC). For a kernel at EL1 with no virtualization, the relevant registers are the non-secure EL1 physical timer:

| Register | Role |
| --- | --- |
| `CNTFRQ_EL0` | Timer frequency, in Hz (read-only, set by the platform) |
| `CNTP_TVAL_EL0` | Countdown value; the timer fires when it reaches 0 |
| `CNTP_CTL_EL0` | Control: bit 0 enables the timer |

Unlike the GIC (Step 9-10 of v0.2), the timer itself needs no base address. However, its interrupt still has to go through the GIC like any other source, as a **PPI** (Private Peripheral Interrupt).

### Finding the timer's interrupt ID

```bash
dtc -I dtb -O dts virt.dtb | grep -A 5 timer
```

```text
interrupts = <0x01 0x0d 0x104 0x01 0x0e 0x104 0x01 0x0b 0x104 0x01 0x0a 0x104>;
```

Four PPIs (`type = 0x01`), one per timer variant. GIC PPI ID = device tree number + 16:

| DT number | GIC ID | Timer |
| --- | --- | --- |
| 13 | 29 | Secure physical |
| **14** | **30** | **Non-secure physical (`cntp_*`) — used here** |
| 11 | 27 | Virtual |
| 10 | 26 | Hypervisor |

## Step 1: Timer Driver

`src/timer/timer.s`:

```asm
.section .text.timer

.global timer_set_interval
.global timer_init
.global tick_count

timer_set_interval:
    mrs x0, cntfrq_el0

    mov x1, #100
    udiv x0, x0, x1

    msr cntp_tval_el0, x0

    ret

timer_init:
    str x30, [sp, #-16]!
    bl timer_set_interval

    mov x1, #1
    msr cntp_ctl_el0, x1

    ldr x30, [sp], #16
    ret

.section .bss
.align 3
tick_count:
    .skip 8
```

`CNTFRQ_EL0 / 100` gives roughly a 100 Hz tick. `timer_set_interval` is called both at init and re-armed on every interrupt (Step 3), since `CNTP_TVAL_EL0` is a one-shot countdown, not a periodic reload.

## Step 2: GIC — Enabling the Timer PPI

`src/gic/gic.s`, `gic_init` extended:

```asm
    // Distributor: enable SGI 0 and PPI 30
    ldr x0, =GICD_BASE
    mov  w2, #0x1
    movk w2, #0x4000, lsl #16
    str  w2, [x0, #GICD_ISENABLER0]
```

`GICD_ISENABLERn` is set-only, it means that writing `1` to a bit enables that interrupt, and writing `0` has no effect.

`0x40000001` doesn't fit `MOVZ` in one instruction. `movk` (Move with Keep) writes one 16-bit slice at a chosen position without zeroing the rest of the register, unlike `mov`/`movz`. So `mov w2, #0x1` sets the low slice, then `movk w2, #0x4000, lsl #16` adds the high slice on top.

## Step 3: Routing the Timer IRQ

`src/exceptions/handlers.s`, `el_irq` extended to dispatch by interrupt ID, and `timer_irq` added:

```asm
el_irq:
    stp x22, x30, [sp, #-16]!

    // moves the interrupt to active
    ldr x0, =GICC_BASE
    ldr w22, [x0, #GICC_IAR]

    cmp w22, #30
    b.eq timer_irq

    ldr x0, =message_irq
    bl uart_puts

    ldr x0, =message_prefix_iar
    bl uart_puts
    mov x0, x22
    bl uart_put_hex

    ldr x0, =message_newline
    bl uart_puts
    
    b eoi

timer_irq:
    bl timer_set_interval           // must re-arm every time

    ldr x0, =tick_count
    ldr x23, [x0]
    add x23, x23, #1
    str x23, [x0]

    tst x23, #0x1FF                 // multiple of 512?
    b.ne eoi

    ldr x0, =message_prefix_tick
    bl uart_puts
    mov x0, x23
    bl uart_put_hex

eoi:
    ldr x0, =GICC_BASE
    str w22, [x0, #GICC_EOIR]

    ldp x22, x30, [sp], #16
    eret
```

`x22` (GICC_IAR) survives `bl timer_set_interval` since that function only touches `x0`/`x1`. The tick count is only printed every 512 ticks (`tst` against `0x1FF`, a power-of-2 mask), to avoid flooding UART at ~100 Hz.

## Step 4: Starting the Timer

`src/boot/boot.s`, one line added after `gic_init`:

```asm
    bl gic_init

    bl timer_init

    msr daifclr, #2
```

```bash
make clean && make

```
